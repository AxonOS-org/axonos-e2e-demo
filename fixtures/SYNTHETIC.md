# Synthetic fixture — not real neural data

`synthetic_trace.csv` is **synthetic**. It was generated by
[`scripts/gen_fixture.py`](../scripts/gen_fixture.py) from integer square waves
plus a deterministic integer LCG "noise" source. It is:

- **not** recorded from any person;
- **not** biologically realistic;
- **not** evidence of accuracy, latency, throughput, or power.

Each 1-second window carries a single rhythm whose period is chosen so the
pipeline's comb-filter energy peaks at a known lag, which the demonstrator
classifier maps to a known intent. The trace is crafted to exercise every code
path: each intent kind, the capability gate, and every consent transition
(suspend, resume, terminal withdraw).

Measured performance evidence, when it exists, lives only in
[`axonos-validation`](https://github.com/AxonOS-org/axonos-validation) with raw
hardware traces — never here, and never mixed with synthetic data.
